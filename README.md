## Recent projects

These are from my MSc at TUS.

- [library-microservices](https://github.com/MorganReilly/library-microservices): a cloud-native library system built with Spring Boot and Spring Cloud. It covers an API gateway with rate limiting, Eureka service discovery, centralised configuration, circuit breakers, OAuth2/JWT security with Keycloak, distributed tracing with Zipkin, and Prometheus and Grafana monitoring. Each service has its own database.
- [subscription-api](https://github.com/MorganReilly/subscription-api): a Spring Boot and MySQL REST API for members and subscriptions, with validation, pagination and structured error handling. It is orchestrated with Docker Compose and delivered through a Jenkins pipeline, with Ansible for provisioning.
- [cdd-assignment-2](https://github.com/MorganReilly/cdd-assignment-2): containerised microservices deployed with Docker Compose, Docker Swarm and Kubernetes, with ELK logging and end-to-end tests.
- [LibraryManagementSystemV2](https://github.com/MorganReilly/LibraryManagementSystemV2): a Java 25 application using sealed classes, records, pattern matching, streams, concurrency and the newest language features.
